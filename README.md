# Defence Probe

### 1. Real-Time Visibility
Provides instant insights into threats, traffic levels, and system health—crucial for rapid response and informed decision-making.

### 2. Comprehensive Threat Monitoring
Tracks and logs various types of cyber threats such as unauthorized logins, port traffic spikes, and failed authentication attempts.

### 3. Unified Security Dashboard
Consolidates key metrics—security score, active threats, and blocked attacks—into a single, accessible interface.

### 4. System Uptime Tracking
Monitors the availability and performance of core components like the Network Scanner and Report Generator, ensuring everything is functioning smoothly.

### 5. Quick Action Controls
Lets administrators immediately initiate full scans, generate reports, or update threat databases without navigating through multiple menus.

### 6. Intuitive Design
Dark theme with clean layout enhances readability during extended monitoring sessions, especially in low-light environments.

### 7. Time-Stamped Event Logs
Keeps a precise historical record of alerts, which is valuable for forensic analysis or compliance auditing.

### 8. Scalability & Local Testing
Running on `localhost` suggests that the platform is designed for flexible deployment—from local environments to production networks.

### 9. Status Feedback & Version Control
Displays current system status and software version clearly—useful for both troubleshooting and update management.
